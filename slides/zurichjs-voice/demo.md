# Live demo: a lesson by voice

About 5 minutes, slide 22. Goal: the room hears ChatGPT read a real exam question, the speaker answers once right and once wrong, and the progress is saved.

## Before the talk
- [ ] ChatGPT on the phone, Swiss Passport added and refreshed (Settings, Plugins, Swiss Passport, Refresh tools); in Claude, «Always allow» chosen.
- [ ] Phone screen mirrored to the projector (QuickTime over cable, or the venue's AirPlay), phone sound through the venue speakers.
- [ ] Do Not Disturb on, notifications off, battery full.
- [ ] One test run at the venue: network and sound.
- [ ] Backup video of the same demo on the laptop, one click away (record it at home with the same script).
- [ ] A fresh progress code written on a card, so the lesson starts clean.

## Script
1. Start voice mode. Say: «I want to learn for the Zurich citizenship test with Swiss Passport, in English. My progress code is …»
2. ChatGPT offers lessons. Choose «The Federal Parliament» (lesson 8, no picture questions).
3. It explains the National Council and the Council of States in two or three sentences, then reads the first question with «A: …, B: …, C: …, D: …».
4. Answer with the words of an option, not the letter (shows the mapping). Answer correctly.
5. On the next question answer wrong on purpose. The feedback says why, in one or two sentences, and the question comes back later in the round.
6. End voice mode. Open swiss-passport.com/learn with the same code and show that both answers are saved.

## If something goes wrong
- It asks its own questions or doesn't call answer: say «Use the Swiss Passport answer tool.» Then point out that this is exactly the bug from the talk.
- No network or sound: play the backup video.
- It asks for permission at every step: that is the «Always allow» trap from slide 19; accept and move on.
