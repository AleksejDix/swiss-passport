Rule 1

The server owns the lesson

  • It hands out one step at a time
  • The model never sees the next question
  • The model never judges an answer: the answer tool does

Models improvise. Learners need the official answer, every time.

3:30. This one rule is what made voice fixable later. If the model owned the state, there would be nothing to repair.

6:20. Reconstructed from the bug, the words are illustrative. Friendly, fluent, correct facts even. And none of it counted: the model asked its own questions, judged them itself, and the server never heard an answer.

Why

  • In voice mode there is no card to look at
  • The note was written for text chats
  • The model followed the note, not the situation
  • Some hosts never read the server instructions

No card to look at

7:10. Server instructions are the MCP place for "how to use me". ChatGPT does not read them. Tool descriptions and tool results always arrive, so that's where the rules have to live.

Making it listen, 1 of 4

The rule travels with every step


// In every step of a voice session:
// ChatGPT's voice mode ignored the card note, asked its own questions and saved nothing.
export const VOICE_STEP =
  "Voice conversation: the feedback (if any) fits in one or two sentences," +
  " explain_first (if any) in two or three. Then comes this question with its" +
  " options A to D, read aloud. The learner's spoken answer is checked and saved" +
  " by the answer tool with their letter; the quiz uses only these questions.";

const data = voice && out.questionId
  ? { voice_instructions: VOICE_STEP, ...out.data }
  : out.data;

Not in a description the model read an hour ago: in the result it reads right now.

  • The letter or the words: mapped to the letter
  • Unclear? Ask again
  • Feedback in one or two sentences
  • No tables, lists, emoji, markdown or ids
  • The German key term once

Write facts, not orders

First version of the voice rule

When the learner answers, call answer with their letter: only answers sent with answer are saved. Never ask other questions and never judge the answer yourself.

ChatGPT: a suspicious instruction. It asked the learner to allow every call.

Now

The learner's spoken answer is checked and saved by the answer tool with their letter; the quiz uses only these questions.

14:00. Orders in a tool result look like prompt injection, so ChatGPT asked the learner to approve every call. Facts say the same thing and let the model decide, and it decides well.
