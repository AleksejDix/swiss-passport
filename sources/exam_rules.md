# Exam rules: Grundkenntnistest Kanton Zürich

Only official sources, quoted verbatim. Checked 2026-09-25.

## Confirmed

| Rule | Original text | Source |
|---|---|---|
| Question pool | Question list with 350 questions; the practice test uses `"quiz":{"questions":350}` | PDF «Grundkenntnistest Kanton Zürich» (zh.ch), practice test |
| Questions per test (practice test) | «Es werden Ihnen 50 Fragen gestellt.» | Übungs-Grundkenntnistest, zh.ch (embedded via Easy LMS, exam-322111) |
| Scoring (practice test) | «Sie haben 14.00 von 50.00 möglichen Punkten erzielt.» Each question «1 von 1 Punkt» | Practice test results page |
| Feedback (practice test) | «Nach der Beantwortung einer Frage wird Ihnen angezeigt, ob Ihre Antwort korrekt ist oder nicht.» | Practice test |
| Question format | 4 answer options, exactly 1 correct | PDF + practice test |
| Topics | «Im Test gibt es Fragen über Geographie, Politik und Geschichte.» | zh.ch/grundkenntnistest |
| Legal basis | § 16 KBüV: Gemeinde prüft die Grundkenntnisse «a. im Rahmen eines Einbürgerungsgesprächs anhand einen standardisierten Fragebogens oder b. durch einen Test.» | KBüV LS 141.11 (OS 72, 2017) |
| Place/date | «Die Gemeinde sagt, wann und wo ich den Test machen kann.» | zh.ch |
| Fees | «Die Gebühren für den Grundkenntnistest unterscheiden sich je nach Gemeinde und Testanbieter.» | zh.ch |
| City of Zurich | «Dieser findet vor Ort im Stadthaus statt und ist kostenlos.» Test «erst, nachdem Sie das Gesuch zur Einbürgerung eingereicht haben.» | stadt-zuerich.ch |
| Exemptions | 5 years of compulsory school in CH (3 of them at Sek I), or a Sek II / tertiary qualification in CH, or currently attending compulsory school / Sek II | zh.ch, stadt-zuerich.ch, § 6 Abs. 2 KBüV |

## NOT officially published (do not invent)

- **Pass mark:** no official page states it. The practice test decides «bestanden / nicht bestanden» on the server; 14/50 was «Nicht bestanden».
- **Time limit:** no official page states it; the practice test has no visible timer.
- **Whether the real test uses the same format as the practice test** (50 questions): not confirmed.
- **Test language:** no official page says in which language the test is taken (zh.ch and stadt-zuerich.ch, checked 2026-09-26). All official material is German only: question list «PDF | 78 Seiten | Deutsch», brochure «PDF | 76 Seiten | Deutsch», and the practice test. So in practice German, but not stated.
