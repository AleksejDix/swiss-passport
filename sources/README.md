# Sources

The quiz is based on official publications of the Canton and the City of Zurich. They are not copied into this repository; download them from the original pages:

| Document | Publisher | Link |
|---|---|---|
| Grundkenntnistest Kanton Zürich (350 questions, PDF, May 2025) | Kanton Zürich, Gemeindeamt | [zh.ch](https://www.zh.ch/content/dam/zhweb/bilder-dokumente/themen/migration-integration/einbuergerung/gkt/grundkenntnistest_kanton_zuerich.pdf) |
| Einbürgerungsbroschüre Kanton Zürich (2024) | Kanton Zürich | [zh.ch](https://www.zh.ch/content/dam/zhweb/bilder-dokumente/themen/migration-integration/einbuergerung/gkt/broschuere_einbuergerung_grundkenntnistest.pdf) |
| Lernbroschüre für den Grundkenntnistest (Dec. 2024, B1) | Stadt Zürich | [stadt-zuerich.ch](https://www.stadt-zuerich.ch/content/dam/web/de/aktuell/publikationen/2024/einbuergerung-lernbroschuere-grundkenntnistest/lernbroschuere-grundkenntnistest.pdf) |
| Kantonale Bürgerrechtsverordnung (KBüV, LS 141.11) | Kanton Zürich | [zh.ch](https://www.zh.ch/de/politik-staat/gesetze-beschluesse/gesetzessammlung/zhlex-ls/erlass-141_11-72-435.html) |
| Grundkenntnistest: information page and practice test | Kanton Zürich | [zh.ch/grundkenntnistest](https://www.zh.ch/de/migration-integration/einbuergerung/grundkenntnistest.html) |

The canton map on the website uses generalised boundaries from the **Bundesamt für Statistik (BFS), GEOSTAT** (via the [swiss-maps](https://github.com/interactivethings/swiss-maps) package), for non-commercial use with attribution. `mcp/scripts/build-map.mjs` turns them into `mcp/public/map-data.js`.

[exam_rules.md](exam_rules.md) summarises what these sources say about the test format.
